# Workshop AI – Chi phí đoàn du lịch

US-02 minh họa ghi khoản chi và tính tiền; dùng dữ liệu giả, chưa có backend, lưu bền vững, thanh toán, phân quyền hoặc đồng bộ. Không triển khai thật trong buổi. Node.js 22 và Python 3 là đủ cho phần chính. Đề bài và prompt mẫu từng bước ở `de-bai/de-bai-sinh-vien.md`; code và test do AI viết trong buổi workshop. `node --test` minh họa các giai đoạn; `node scripts/kiem-tra-ci.mjs` là cổng kiểm tra nghiêm ngặt (không chấp nhận TODO hoặc thiếu test). Tài liệu chạy thử cũ chỉ là kết quả lịch sử.
